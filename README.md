## DMIT 49.99 套餐是什么，值不值那个价

先说清楚我们在聊哪个套餐。

**LAX.AN4.Pro.MALIBU**，DMIT 洛杉矶 Premium 系列下的限量特惠款，年付 $49.9 美元。配置是 1 核 CPU、1GB 内存、20GB SSD 硬盘、1TB 双向流量、1Gbps 带宽，配一个 IPv4 和一个 IPv6 /64。

不值的地方也有：1GB 内存说实话偏小，跑一个代理绰绰有余，但你要部署个有数据库的应用就要掂量了；20GB 硬盘也不算宽裕。纯个人使用、科学上网、小型中转，这个配置够用。重应用建议上高配套餐。

## 买之前要知道的几件事

**注册有等待期。** 新账号注册后一般需要 7 天才能下单，热门补货套餐速战速决，提前注册好账号很有必要。

**SSH 默认密钥登录。** DMIT 的机器不是用密码登录的，是密钥方式。在控制面板的 Access 选项下可以下载密钥包，里面的 .ppk 文件配合 PuTTY 用，或者用 OpenSSH 格式直接连。对新手来说这步容易卡，提前了解一下。

**流量是双向计算的。** 上传和下载都计入流量，不是单向。1T 流量在科学上网场景下实际消耗比你想象快，跑视频的话要注意控制。

**超量有保障。** T1 系列流量用完后不停机，自动限速继续使用（洛杉矶 T1 限速到 100Mbps，香港/东京 T1 限速到 50Mbps），等月初重置自动恢复。Pro 和 EB 系列超量后服务暂停。

**IP 被墙怎么办。** 每 15 天可以免费申请更换一次 IP，换 IP 提交后需要手动重启实例才生效。目前 LAX Pro/EB 系列支持自助更换，不用等客服处理工单，效率高了不少。

**退款政策。** 3 天内流量使用不超过 30GB 可以全额退款（退到账户余额）；30 天内按剩余价值部分退款。拿不准适不适合自己，先买最小配的试，不对路及时退。
